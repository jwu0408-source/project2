   # PowerShell에서:
   cd C:\big21\Project2
   venv\Scripts\Activate.ps1
   uvicorn contact_app.main:app --host 0.0.0.0 --port 8000 --reload

   # 또는 CMD에서:
   cd C:\big21\Project2
   venv\Scripts\activate.bat
   uvicorn contact_app.main:app --host 0.0.0.0 --port 8000 --reload

   출력 예시:
   INFO:     Uvicorn running on http://0.0.0.0:8000
   INFO:     Application startup complete

## ⚠️ 문제 해결

❌ "포트 8000이 이미 사용 중"
   해결: 기존 Backend 프로세스 종료 후 다시 실행
   또는 다른 포트 사용: --port 8002

❌ "데이터베이스 연결 실패"
   해결: contact_postgres 컨테이너가 실행 중인지 확인
   docker start contact_postgres

❌ "401 Unauthorized" 에러
   해결: 로그인 페이지에서 회원가입 후 로그인
